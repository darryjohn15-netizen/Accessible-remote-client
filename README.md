# Accessible-remote-client Accessible Remote Client is a remote access and control app for blind, low-vision and visually impaired people, and for everyone who uses any Android screen reader, such as TalkBack, Commentary Screen Reader (Jieshuo+) and others. It connects Android to Android, and Android to a Windows computer running NVDA. You only need a server domain and a shared secret key. Phone-to-phone connections are end-to-end encrypted through a relay server. Phone-to-computer connections are encrypted between each device and the server.

Both phones must use the same screen reader. The app works with any Android screen reader, but different screen readers, such as TalkBack and Commentary Screen Reader (Jieshuo+), use different gestures, focus handling, actions menus and announcement timing, so a gesture or focus change sent from one screen reader can be understood differently on the other phone and cause wrong actions or glitches. The app checks this when you connect and pauses remote control until both phones match. A phone with no screen reader running, for example a sighted helper's phone, is allowed.
All help is in one place, in short sections: Quick Start, Setup, Screen Reader Configuration, Connection, File Transfer and Media Streaming, Sounds and Announcements, the two computer sections, Keyboard Commands, Troubleshooting, and Contact. Each section page uses headings, so you can jump through it by heading.
